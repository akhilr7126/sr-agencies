# SR Agencies Website - MVP

This is the codebase for the SR Agencies Property Management website.

## Tech Stack
- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: CSS Modules (Vanilla CSS)
- **Icons**: Lucide React

## Getting Started

Since this project was generated in an environment without Node.js pre-installed, you need to ensure you have Node.js (v18+) installed on your machine.

1.  **Install Dependencies**:
    ```bash
    npm install
    # or
    yarn install
    ```

2.  **Run Development Server**:
    ```bash
    npm run dev
    # or
    yarn dev
    ```

3.  **Open Browser**:
    Navigate to `http://localhost:3000` to view the site.

## Structure
- `src/app`: Page routes and layouts.
- `src/components`: Reusable UI components (Navbar, Footer, Button).
- `src/app/globals.css`: Global design tokens and styles.

## Features
- Responsive Design (Mobile First)
- NRI Focused Pages
- Lead Capture Forms (UI)
- WhatsApp Integration
